# 寶物教室 Windows 64 位元試用版

這是可解壓縮執行的伺服器試用包，不是已完成 Windows 真機驗證的正式安裝程式。內附官方 Node.js 執行檔，不需要老師自行安裝 Node 或 npm。請先完整解壓縮，不要在壓縮檔內直接執行。

## 第一次設定

1. 雙擊 `01-本機啟動.cmd`。程式只監聽 127.0.0.1，不直接開放家用路由器的連接埠。
2. 開啟 http://127.0.0.1:4180 ，選「老師入口 → 第一次使用，註冊帳號」。
3. 使用自己的 Email 作為帳號名稱，設定至少 8 字元的密碼，填入伺服器視窗顯示的首次設定碼。本機版不寄 Email 驗證信，一份資料庫只有一位老師；設定碼不要給學生。
4. 建立班級。到「AI 與設定」儲存老師自己的 Gemini Key；金鑰加密保存在本機，不需要 Firebase 或 Render。
5. 關閉伺服器視窗，結束本機初始化。

## 外網試用（不是正式上課的穩定性保證）

`02-外網試用.cmd` 使用 Cloudflare Quick Tunnel，需網路連線。它是官方限定測試／開發用途的通道，沒有 uptime 保證，且一次最多 200 個正在處理的 HTTP 請求（不是 200 名學生）。正式班級長期使用需另選適用且穩定的通道；本程式可接自己的 HTTPS 通道。

1. 閱讀啟動器所列的 Cloudflare 條款、隱私政策及限制。願意使用再輸入指定字樣繼續。
2. 啟動器取得本次隨機 HTTPS 網址並開啟伺服器；不要關閉視窗。
3. 老師仍從 http://127.0.0.1:4180 登入，按「開始上課」。
4. 在「班級與連線」頁選擇班級，按「開放新生註冊」及「複製學生入口」，將完整連結分享給學生。連結包含本次外網網址與班級代碼。
5. 學生在手機、平板、電腦的瀏覽器開啟連結，用姓名＋生日月日註冊。下次仍用相同資料登入，無需重新註冊。相同班級的同名學生需由老師指定不同辨識名稱。
6. 註冊完成可按「關閉註冊」。下課按「結束課堂」會登出學生，再關閉伺服器與通道。

隨機網址每次可能不同，下次上課重新分享連結即可，學生資料仍在老師電腦。老師電腦不能休眠，網路中斷就會斷線；此包尚未完成 Windows 防火牆、真機多裝置與外網負載測試。

## 使用自己的 HTTPS 通道

設定環境變數 `CLASSROOM_PUBLIC_URL=https://你的公開網址`，讓自己的通道轉送至 http://127.0.0.1:4180，再執行 `01-本機啟動.cmd`。不要把資料資料夾當成網站根目錄。正式通道、網域或既有學校服務可能有成本，不能宣稱所有外網連線永遠免費。

## 資料與備份

- 資料在 `%APPDATA%\TreasureClassroom`，不在程式解壓縮目錄。
- 每次啟動會自動備份至該資料夾的 `backups`。請定期把整個資料夾備份到安全位置，並自行清理不需要的舊備份以免磁碟用滿。
- `classroom.sqlite` 保存帳號雜湊、班級與收藏，`server.key` 是加密秘密。還原時先關閉伺服器，從同一份備份複製這兩個檔案回資料資料夾；不能只還原其中一個。
- 首次設定後不能由外部新增老師。此版尚未提供忘記密碼郵件、自動帳號恢復或資料匯入 UI，請妥善保存老師密碼。
- 生日月日只有少量組合，不是強密碼。只在班內分享連結，不保存敏感學籍資料。登入限制每個學生每 15 分鐘 5 次；整個網頁入口每 15 分鐘 120 次。

## 費用

本機伺服器沒有雲端主機月費，但使用老師電腦及網路。Gemini 的免費額度與計費狀態仍由老師的 Google 專案決定；已啟用計費的金鑰可能產生費用。第三方通道免費政策也可能更改。程式不自動購買、升級或綁定付款方式。

官方通道限制：https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/

## AI 模型更新

預設模型為 Gemini 3.5 Flash-Lite（`gemini-3.5-flash-lite`）。更換新版程式後請先關閉舊伺服器，再重新啟動；「AI 與設定 → 使用模型」應顯示此代號，再按測試連線。若仍顯示舊模型，請檢查是否自行設定了 `GEMINI_MODEL` 環境變數，它會優先於程式預設值。金鑰不需因更新重新建立。

官方列有免費層級，但仍依老師專案的權限、地區及額度；請使用未啟用計費的專案維持免費限制。模型說明：https://ai.google.dev/gemini-api/docs/models/gemini-3.5-flash-lite ；費用：https://ai.google.dev/gemini-api/docs/pricing

## 可選題數與 AI 批改

在「教學與出題 → 建立學習任務」選 AI 出題數量（1–20 題）。產生後核對並保存／發布。
學生交卷後，到「學習觀察 → 查看作答」，非選擇題任務可按「AI 一鍵批改與回饋」，會填入建議總分與回饋，並顯示逐題證據、已掌握概念、待加強與補強建議。總分採每題等權，選擇題依標準答案計算。證據不足時需老師補充分數。老師核對後按發布才保存正式評分與發放獎勵。
作品題目前依學生提交的文字說明評估，沒有作品內容時不能當成已檢視實際作品。AI 批改結果是本次作答的學習建議，不是對學生能力的定論。


## 已保存的 AI 結果

AI 批改建議與教師分析會自動保存在老師的資料庫。關閉視窗、重新整理或重開伺服器後，從「學習觀察 → 查看作答」即可再次閱讀。需要新的結果時按「重新 AI 批改」或「重新分析」；失敗時保留上次成功結果。批改建議仍須老師發布才成為正式回饋，不會自動發放代幣。舊版關閉時已丟失的結果無法恢復，更新後產生的結果才會保存。


## 任務獎勵
新任務預設每題 1 枚代幣，增刪題目時自動調整；可改為老師自訂總枚數。發布個別學生回饋前也可修改本次 0–100 枚，0 表示只發布回饋。已發布的回饋不會因再次開啟而重複發幣。本次更新包含後端規則，請先關閉舊伺服器，再自行啟動新版。


## 學生逐題回饋
學生交卷成功後，選擇題立即顯示正確答案、對錯及題目原有詳解；未填詳解會提示老師尚未補充。老師批閱可逐題編輯回饋，AI 建議填入後仍須老師確認發布。學生只會看到自己已交卷的答案及正式發布的回饋；非選擇題不提前揭露參考規準。舊批閱沒有逐題資料時會明確提示，不虛構回饋。此版需自行重啟教師伺服器。

# 官方開放資料快照

本版的 `open-data.json` 是公開資料的欄位整理及格式轉換，不包含學生、教師帳號或 API Key。

| 原資料集 | 提供機關 | 原始來源 |
|---|---|---|
| 國民小學名錄（6087） | 教育部統計處 | https://data.gov.tw/dataset/6087 |
| 國民中學名錄（6088） | 教育部統計處 | https://data.gov.tw/dataset/6088 |
| 國家教育研究院愛學網（6318） | 國家教育研究院 | https://data.gov.tw/dataset/6318 |

清單依政府資料開放授權條款第1版提供：https://data.gov.tw/license 。已保留資料集、下載來源、查核日期與原檔 SHA-256。本專案與原機關無背書或認證關係。

學校資料保留年度、代碼、名稱、縣市與學制；未打包學校電話及地址。愛學網保留公開教材描述、分類、學習對應、原站網址與影音授權標示；未下載或重製影片、圖片、字幕。清單授權不等於個別影音的授權；請到原站依該影音條款使用。

2026-10-03 隨附快照：115學年度國小2,609筆，國中104–115學年度共8,875筆（115年度740筆），影音清單4,455筆。不含另列的附設學部，不代表全臺所有就學機構；影音清單也不是题库。

來源模板題目與詳解為本專案整理，非教育部官方試題。正式發布前仍須教師核對範圍、題意與適齡性。已確認的原題可沿用題庫核准。手動更新從固定官方端點下載，完整驗證後一次切換；原快照隨教室加密備份保存以支持歷史題目追溯。

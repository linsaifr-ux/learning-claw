# 學習有爪：三至九年級興趣研究、模型設計與永續營運方案

研究整理日期：2026-09-27。狀態：文獻整理與設計規格，尚未完成學生訪談、模型精製或成效驗證。文中數量、效能與時程均為本專案提出的試行目標，不是研究證實的標準。

## 一、研究能告訴我們什麼

| 資料 | 可採用的發現 | 適用限制與本案決策 |
|---|---|---|
| 兒福聯盟《2025年兒童休閒娛樂現況調查》[1] | 台灣五至九年級學生的休閒包含大量影音與遊戲活動 | 不能推論三、四年級，也不是娃娃或收藏主題喜好排名；平台要服務課堂，避免把增加遊戲時間當成果 |
| Ofcom《Children and Parents Media Use and Attitudes Report 2025–6》p.18 [2] | 英國3–17歲兒少遊戲類型中，創造／建造類54%、益智／問答類40% | 廣泛年齡的英國調查，不是台灣三至九年級分組數據；支持試做房間創作與組合玩法，不能據此認定某種動物最熱門 |
| UNICEF RITEC 2024及設計工具箱 [3][4] | 數位遊戲設計可支持自主、能力感、創造、身分表達與關係等面向 | 不代表所有遊戲都有效；本案轉譯為自主選主題、佈置、可理解的成長回饋與教師管理的展示 |
| López-Fernández等，VMQ研究（2020）[5] | 遊戲動機包含客製化、幻想、認知挑戰與社交等不同面向 | 青少年驗證樣本407人、平均約15歲、來自西班牙兩所中學的便利樣本；不能直接套用至國小或把量表當台灣兒童診斷 |
| Sailer與Homner（2020）統合分析 [6] | 遊戲化對學習結果有正向證據，但動機及行為效果在較嚴格研究子群中較不穩定 | 不可宣稱「精緻娃娃必然提升成績」；分開追蹤教學成效和遊戲偏好 |
| Tsay等（2020）新奇效應研究 [7] | 大學情境討論初期熱度下降，以及教學／遊戲化設計與動機轉變 | 是長期設計的警示，不是本案8–15歲使用者的直接證據；需跨週追蹤而非只看首次喜好 |

結論：目前證據較能支持「怎樣讓學生有選擇、能創作、感到進步」，不足以支持「三年級喜歡熊、九年級喜歡機器人」這類精確分類。以下主題是待驗證假設，所有年級皆可選擇，不按性別鎖定內容。

## 二、年齡分層與共同設計

| 試用分組 | 優先驗證的體驗假設 | 模型與介面應提供的選擇 |
|---|---|---|
| 國小三、四年級，約8–10歲 | 是否較容易理解表情、明確輪廓與一步完成的搭配 | 動物伙伴、小型探險道具；也可選機械、化石。先提供現成搭配，再開進階佈置 |
| 國小五、六年級，約10–12歲 | 是否開始重視系列收藏、組合創作與個人風格 | 可更換配件、可拼接場景、自然觀察收藏；比較可愛與寫實風格偏好 |
| 國中七至九年級，約12–15歲 | 是否需要較成熟的材質、風格自主與作品展示 | 機械、音樂、運動、礦物與設計收藏；可保留可愛收藏，不把成熟等同黑色或機器人 |

這是測試分組，不是心理發展定論。先做每組8–12人的探索試用，招募喜好不同、設備不同的學生；樣本只供設計發現，不宣稱具有全台代表性。另訪談6–10位教師，了解設定時間、課堂干擾與內容更新負担。

### 可直接使用的學生訪談題

1. 從主題圖卡選三個最想收藏的，也可選「都不喜歡／自己畫一個」。圖卡順序隨機。
2. 你喜歡它的造型、顏色、材質、故事，還是能拿來佈置？請指出一個部位。
3. 同一角色的柔軟布偶版、寫實模型版、設計公仔版，你選哪個？先不顯示稀有度。
4. 拿到寶物後，最想換裝、擺房間、看介紹、和同學展示，還是繼續收集？
5. 哪裡太幼稚、太複雜或不好操作？用手機再試一次。
6. 一週後還記得哪件？兩週後還會使用哪件？不提示學生必須喜歡。

試用由學校／家長依情境同意，學生可不參加，不影響代幣與成績。只保存分組、匿名偏好與操作問題，不收姓名、生日、公開房間連結或廣告識別資料。先用教師主持的小規模試用，不立即新增全站追蹤。

## 三、模型主題與第一批設計

保留現有六台及既有收藏ID，先升級代表作品品質，再依偏好新增主題。每一款至少有前／側／背設計、材質樣本、配件接點與手機實機展示。下列均為原創設計，不使用熱門動漫或遊戲角色替代研究。

| 系列 | 首批候選模型 | 精製要求 | 長期變化方式 |
|---|---|---|---|
| 森林伙伴 | 赤狐郵差、水獺園丁、既有星霜白熊升級 | 布料方向、縫線、耳內與腳掌材質、立體五官；不要只有球體拼接與換色 | 共用帽／頸／背部接點，郵包、雨帽、圍巾可跨角色使用 |
| 海洋觀察 | 既有座頭鯨、海龜、透明水母 | 鯨腹溝與鰭形、龜甲分區、透明度分層；避免過量透明物件 | 礁石底座、海草、觀察牌構成小型生態展示 |
| 太空與機械 | 既有機器人、月面探測車、火箭 | 面板接縫、輪胎、金屬／烤漆差異、結構可信度 | 輪組、工具臂、停機坪共用模組；非付費數值升級 |
| 自然博物館 | 紫水晶簇、菊石、甲蟲標本模型 | 晶面、殼紋、比例；區分收藏造型與科學示意 | 展示座、燈具、說明牌，組合個人小博物館 |
| 音樂與生活設計（候選新系列） | 桌上合成器、迷你鼓組、設計檯燈 | 琴鍵／旋鈕、鼓皮、木紋與金屬細節；可愛與簡約兩種提案 | 書桌、音樂角落、海報框，與原房間相容 |
| 運動與街頭創作（候選新系列） | 原創滑板、籃球展示架、運動鞋模型 | 板面圖樣、鞋面布料、鞋帶及球面紋理 | 色板與圖形貼片搭配；不使用品牌標誌 |

先精製3件代表作：星霜白熊（柔軟材質）、機器人（硬表面）、座頭鯨（有機曲面）。原因是可利用現有資產、涵蓋三種主要製作難題，並非已證明這三款最受歡迎。通過偏好與效能試用後再擴充至12件；新系列未驗證前不直接增加機台數。

### 製作流程與品質門檻

- 工具：Blender製作、雕刻、UV與貼圖；輸出GLB，沿用Three.js顯示與Rapier碰撞。Blender官方功能與glTF材質規格見[8][9]。AI概念圖若使用，僅供視覺探索；不能把概念圖當成已完成3D模型。
- 美術方向：有可信材質的收藏玩具。精緻度來自輪廓、比例、接縫、材質與打光，不靠無限制增加面數。
- 將高細節烘焙成法線／粗糙度貼圖；為手機製作低細節版本。暫定一般收藏8k–20k三角形、低細節2k–5k，主要貼圖1024px，近距離必要時2048px。這是起始預算，需按同屏數量調整。
- 暫定單件壓縮資產目標1–3MB、機台首批資產15MB內；只載入當前機台，收藏圖卡使用縮圖。每個目標都要量測，不把檔案大小直接等同GPU記憶體。
- 手機實測目標30fps以上；記錄設備、瀏覽器、同屏物件量與最慢情境。桌面Chrome測試不能代替Safari、iPad或Android真機測試。
- 顯示模型與碰撞模型分開；吊飾、帽緣與輪組需碰撞合理。更換碰撞外形時更新物理版本，已付代幣當局保留原版本以供後端重播。
- 每款測試六視角、明暗環境、左右部位色差、配件穿模、出口落獎、圖卡／獲獎／房間外觀一致。既有白熊曾有局部未換色，因此材質共用與名稱後綴需列入回歸檢查。
- 精製驗收：縮小仍可辨識、近看沒有UV接縫破綻、材質可區分、無穿模、手機流暢；若學生只說「比較亮」卻無法辨識差異，不能算完成品質提升。

## 四、讓平台持續被使用

核心循環：學習與訂正 → 看得懂的逐題回饋 → 自主選擇收藏目標 → 創作自己的房間 → 回顧進步。遊戲獎勵服務學習，不要求每天登入。

建議下一步功能（尚未實作）：

1. 收藏願望清單：學生選擇想探索的主題，教師只看班級匯總。不要依單次點擊認定喜好。
2. 房間套件：地板、展示架、燈具、桌面與配件共用尺寸；新內容可與舊收藏組合，舊收藏不因更新失效。
3. 重複收藏用途：保留、擺多件，或由老師開啟明確比例的裝飾材料兌換。學生看得懂且自行確認，不自動消耗收藏。
4. 有確定結果的獎勵途徑：老師可因完成訂正或個人成長直接頒發指定收藏，避免所有獎勵都取決於夾取技術與運氣。此為新增規則，需另做權限及扣發重複防護。
5. 小型班級策展：學生自願提交佈置作品，由教師核准後只向本班展示；不以按讚排行榜、公開聊天或交易維持熱度。
6. 每4–6週試行一個小型內容包，例如一個底座、一件配件及一項房間創作主題。節慶內容定期回歸、舊收藏永久保留，不設錯過就失去的連續登入獎勵。
7. 教師可停用動畫、關閉遊戲、只用任務與回饋；學生不玩遊戲仍能完整學習。

## 五、永續營運與免費使用

「免費使用」仍有開發、美術、測試、客服、電力、網路與資料備份成本，不能承諾第三方API或通道永久免費。既有老師電腦伺服器可減少集中主機需求，但班級連線能力仍受上傳頻寬與設備效能影響。

| 成本／風險 | 設計方式 | 追蹤方式 |
|---|---|---|
| 模型持續製作 | 原創共用骨架、配件接點、材質庫與小型內容包；先精製少數代表作 | 每件實際工時、資產重用率、學生選用理由 |
| 網路與下載 | 資產版本化、增量內容包、快取；舊包與存檔相容 | 每次更新大小、學生首次載入時間、老師上傳量 |
| AI額度 | 教師自備金鑰、結果快取、題庫重用、批次前顯示工作量；失敗不自動無限重試 | 每班AI用量、失敗率、人工修訂率；無料額度用完仍能用既有題庫 |
| 維護 | 引擎更新與內容包分開；穩定ID、可回復版本、備份／還原演練 | 更新成功率、資料還原成功、每班支援時間 |
| 收入來源 | 免費自架核心；由學校／機構付費委託部署、研習、專屬內容或自願贊助 | 實際合作意願與服務成本；不向學生販售代幣／抽取次數 |
| 授權 | 保存每個模型、貼圖、字型、音效的作者／來源／授權／修改紀錄 | 無法證明可散布的資產不進下載包 |

成本計算模板：每月總成本 = 開發工時×內部時薪 + 美術工時×內部時薪 + 維護支援工時×內部時薪 + 實際主機／流量／其他費用。再除以活躍教師數。全部填實測數據，不以免費軟體推論營運成本為零。

免費自架是產品方案；學校採購、內容合作與贊助是待驗證營運假設，並非已有收入。先以3–5個試行班級估算支援負担，再決定擴大規模。

## 六、8週試行與決策門檻

- 第1–2週：整理訪談與匿名圖卡偏好，精製三件代表作品的設計稿；確認哪些嫌幼稚、哪些辨識困難。保留不同主題選擇。
- 第3–4週：完成三件GLB與配件接點、材質和碰撞驗收，在手機、平板、Windows和Mac測試。模型未通過不擴量。
- 第5–6週：小班試用收藏＋房間創作；保持教學任務及代幣規則一致，降低多項變動造成的混淆。
- 第7–8週：查看隔週偏好、任務訂正完成情形、教師操作時間與學生疲乏理由，決定擴充、修正或下架候選內容。

這是試行排程，需依招募、美術人力與真機取得調整。沒有隨機對照與足夠樣本，不報因果成效。

主要指標：教師四週後自願續用比例、每堂額外管理分鐘、學生是否理解回饋及完成訂正、沒有遊戲時是否仍願意做任務、不同年級和設備的完成率。收藏偏好、配件使用率與房間再次編輯作為內容指標，遊戲時長不列成功KPI。另記錄挫折、同儕比較與過度追求稀有物品的回饋。

初步上線門檻（專案自訂）：所有資產可追溯、舊收藏零遺失、代幣不重複扣發、主要學生設備可完成操作、教師能在一次示範後獨立開關活動。喜好分數低的主題先改，不因已花成本而大量生產。

## 七、目前專案差距與執行順序

已具備：六台主題機台、18款收藏、配件與房間、教師開放控制、活動頁內預覽、三平台試用包。

尚缺：台灣目標學生偏好資料、高細節貼圖與統一美術驗收、成熟的資產內容包機制、完整真機效能資料、跨週教學與續用數據、可量化的維護成本。現有程式幾何模型屬可用原型，不能視為已完成精緻模型製作。

執行順序：先完成三款代表作與訪談圖卡 → 驗證選擇及材質 → 建立共用資產規格與版本 → 房間組合套件 → 小班追蹤 → 才擴大模型庫。現有學生收藏ID及資料不得為了重新設計而刪除。

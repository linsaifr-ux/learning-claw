# v0.1.55 開放資料教學流程交付

狀態：已實作可驗收的桌面教室功能；不是全平台商業上市認證。新入口僅在 Mac／Windows 教師伺服器模式出現。正式教師資料庫未被測試讀寫，使用者自行重啟新版。

## 本次完成

1. 三項官方資料隨包提供並支援手動更新。國小及國中按學年度隔離、代碼保留前導零，愛學網按實際 CSV 解析多行及引號。固定 HTTPS 來源、禁止重新導向、20 秒單來源逾時及8MB上限；來源異常或筆數驟減時不啟用新資料。每次切換在 SQLite 交易內完成。
2. 原始資料雜湊與歷史版本保存。公開快照壓縮存入教室 SQLite，沿用既有加密備份；舊題、舊教材可依原版本解析。相同來源雜湊不重複新增快照；不因更新而變更歷史題答案。
3. 班級與連線頁增加選填教學背景：單校、跨校、不指定。學校背景由教師自行選擇，不代表任教身分認證；同校不同老師不共享權限。找不到可不指定學校，學生不用填校名。
4. 建立任務增加三種官方資料模板：兩縣市名錄合計、差值、資訊判讀。題幹含表格文字、年度、範圍及單位。程式計算答案；教師確認後同步入庫。後端核對模板、數據、詳解與答案，修改後不能冒用資料驗證。沿用相同／相似題檢查。
5. 任務可附最多三份愛學網教材，按領域及學習階段篩選，提供搜尋依據與原站連結。明顯教師研習內容排除；未知範圍不自動放寬。切換年級或科目清除原選取教材，後端再核對範圍。無合適教材不阻止單獨發布題目。
6. 學習觀察頁可選補強教材、明確保存草稿，並隨逐題回饋或學生分析發布。草稿不提供學生；更新回饋不重複授幣。
7. 可依已提交的選擇題錯答建立個別補強草稿，到「教學與出題」核對與發布。每份原作答最多一份補強任務；沿用原題複習並明確允許重題。只有指定學生可見、可提交，預設每題1枚，教師可調整。點教材不授幣，提交後經教師批閱才授幣。
8. 個別補強及教材草稿納入資料刪除與匯出。刪除學生會移除其補強任務，匯出不含別人的個別任務；公開快照保留，不混入學生識別資訊。

## 操作入口

- 教師題庫 → 官方開放資料：查核日期、來源、版本及更新。
- 班級與連線 → 教學背景：選填學校。
- 教學與出題 → 建立學習任務 → 用開放資料建立讀表任務：選年度、學制與兩縣市；會明確詢問是否替換目前題目。
- 同一任務編輯視窗 → 選擇官方教學／補強教材：搜尋與附加。
- 學習觀察 → 查看作答：保存教材草稿、發布回饋、建立個別補強草稿。

## 驗證方法

`tests/open-data.test.mjs` 覆蓋年度去重、原始代碼、範圍查詢、URL與版本偽造、程式計算、資料改動阻擋、題庫確認與發布、學生答案保密、個別補強權限與重複授幣、CSV、原子更新失敗回退、重啟後歷史版本、學生刪除及匯出隔離。

`scripts/check-open-data.mjs` 使用隔離資料庫與合成帳號，驗證學校查詢保存、三題核准、發布、390px手機作答、官方來源顯示、無結果提示、教材草稿與發布、學生查看、個別補強及代幣。教材附件案例只驗證流程，不能當成適切性評測。

實際官方更新測試使用記憶體 SQLite，三份下載成功約4.9秒；確認2,609筆115國小、740筆115國中、4,455筆影音清單。這是單次網路測量，不是效能保證。手機畫面已檢視，無頁面水平溢出。

最終完整回歸244項全部通過；桌機與390px手機端到端流程通過。未使用真實學生或教師API Key進行測試。

三平台試用包的後端、資料檔及前端逐檔一致性核對通過。兩種 Mac ZIP 解壓後的執行權限、framework 連結與本機 ad-hoc 簽章驗證通過；Apple Silicon 從新解壓安裝包完成啟停、註冊、復原碼輪替、加密備份匯出／預覽／還原、新密碼登入及關閉確認測試。這不等於 Apple 公證，也不代替 Intel 或 Windows 真機驗收。

## 尚未完成的上市門檻

- 全科學年題庫覆蓋、領域教師內容審定仍未完成，不能因為加入清單便宣布全科題庫完成。
- 本版三種資料模板仍逐題確認，核准原題可重用；尚無跨教師共用的「模板通用審定」制度。
- 教材搜尋目前為本機欄位／關鍵字檢索，尚無經教師標定的40組語意相關性評測。教師需預覽教材；不宣稱90%推薦正確率或學習成效。
- 個別補強只由選擇題錯答建立；非選擇題的結構化概念診斷、AI自動推薦仍是後續項目。可由老師手動搜尋與附教材。
- 學校來源目前設定到115學年度；新年度來源網址須由版本維護更新。附設學部、學生人數統計、會考通過率未在本次新增。
- Windows及Intel需真機驗收；Mac尚未Developer ID簽章／公證。Quick Tunnel仍可能更換網址，沒有服務可用率承諾。
- 公開來源下架或權利變更仍需維護者處理；本版不下載影音，不用影音連結存在推定已取得改作授權。

不能把「程式測試通過」等同教材正確率、學習成效或已可全面商業上市。應先以小規模教師試行完成內容與跨裝置驗收。

# 學習偵探社 v0.1.62

驗收日期：2026-10-07。此版完成桌面伺服器的角色、案件、學生調查、徽章及資料生命週期。功能完成不等同已通過公開上市的所有驗收。

## 教師操作

1. 在「教學與出題」準備並發布學習任務；尚未有學生交卷的任務才能改編案件。
2. 展開「角色與推理任務 → 角色工作室」，上傳原創或有權使用的 PNG/JPEG/WebP 圖片、角色名稱、來源說明並保存。每班最多 12 位角色。
3. 選擇任務並編輯案件。可自行撰寫，也可使用已設定的教師 Gemini API 編寫場景、提示、證據和結案問題。基本範本只是骨架，不能當作已完成的教學故事。
4. 預覽各站、原題、提示、線索、結案答案與徽章，調整至適齡且合理後一次確認發布。AI 只處理已發布題目，不修改原始題目、答案或評分規準。
5. 學生作答交回既有「學習觀察」，沿用批改、逐題回饋、分析與代幣流程。推理徽章與代幣分開，不因抽徽章額外扣幣或發幣。

發布後案件與原題鎖定。每份任務只有一個案件；已有人交卷時須另建任務，避免既有成績與調查進度不一致。最多保存 100 件案件。

## 學生操作

「學習任務 → 學習偵探社」接受委託，閱讀場景、作答，按「保存作答並取得證據」。已保存的各站作答存於老師伺服器，重開可繼續，保存後不能修改。尚未保存的輸入只有離頁警告，沒有逐字跨分頁同步。

完成全部調查站後，選擇結案推論並寫出證據。結論正確後正式交卷；文字理由保存為推理歷程，不會自動判定理由品質。選擇題立即可查看答案與詳解，非選擇題沿用教師批閱。

每案最多一枚免費角色徽章。三種款式等機率抽取未擁有款，首次各 1/3、取得一款後剩下兩款各 1/2。集滿不重抽，保留通關紀錄。可選擇完成即可領取，或成績達門檻；非選擇題須等教師正式發布評分。收藏中最多展示三枚，再點一次即可取下。

## 權限、資料與防重複

- 學生不能呼叫教師 AI、上傳角色或發布案件。
- 學生投影不提供未解鎖線索、結案正解、其他學生進度或角色來源管理資料。
- 伺服器核對學生身分、班級、個別補強對象、調查順序及獎勵條件；忽略客戶端傳入的分數或徽章款式。
- 保存作答、交卷與獎勵支援重試，不重複交卷或領取。
- 徽章、進度及展示選擇納入備份、學生資料匯出和刪除流程。
- 刪除角色需確認，一併撤除相關案件、進度與徽章，但保留正式學習作答與成績。
- 圖片在瀏覽器縮為 256 × 256 PNG；限原檔 4 MB、解碼面積 2500 萬像素，轉換後資料 URL 不超過 180,000 字元。伺服器再查格式、尺寸與長度。不是外部圖片網址或 SVG。

## 已執行驗收

- 新增 10 項領域／真實桌面服務測試：權限、隱藏資料、序列、重試、成績門檻、款式集滿、展示所有權、撤除、匯出刪除與伺服器重啟保存。
- 桌面及一般網頁建置成功；完整自動測試 269 項通過、0 失敗。
- 以隔離班級及原創測試圖片實際操作：教師上傳、AI 測試替身生成、預覽、發布；學生在 390px 寬度作答、重開續玩、結案、抽徽章、查看原題詳解、展示收藏。
- 手機截圖發現全域按鈕排版干擾徽章文字，已修正並重新檢視；案件抬頭亦改用局部樣式，避免主頁頁首樣式干擾。

## 尚未通過的上市條件／目前界線

- 真實 Gemini 生成品質尚未做跨年級、跨科目抽樣驗收；本次流程驗收使用可控測試替身。教師預覽確認不可移除。
- 角色為 2D 立繪；徽章展示板是寶物房頁面上的 2D 展示區，尚非可在 3D 房間中任意擺放的家具。
- 沒有學生自由 AI 聊天，也未內建任何第三方卡通角色或授權素材。上傳聲明不代表系統已審定素材權利。
- 此功能正式連線適用教師桌面伺服器；Firebase 模式不顯示未支援的入口。
- 尚未在實體 Windows／Intel Mac、Safari／iOS／Android 全矩陣驗收，亦未執行多人同時上課壓力測試。
- 桌面包延續本機 ad-hoc 簽章，非 Apple Developer ID 公證或 Windows 正式程式碼簽章。
- 瀏覽器測試工具的 WebMCP 註冊取消曾產生 AbortError 診斷；未阻斷操作，未將其描述成零錯誤驗收。

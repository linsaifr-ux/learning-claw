# v0.1.50 全面檢查與上市判定

檢查日期：2026-10-01。範圍：教師電腦伺服器、師生網頁、AI／RAG 流程、代幣與遊戲、收藏房間、套件與安裝包。正式課堂資料未讀取、修改或用來壓測，原服務未由本次檢查重新啟動。

**判定：可繼續受控試行，尚不符合正式商業上市條件。** 本輪完成可重現問題的修復與擴充驗證；不代表所有情境已驗證，更不能證明 AI 題意、答案與批改永遠正確。下列未通過門檻必須結案後才可改判。

## 驗證證據與邊界

- Node 單元／服務整合測試：**211 項通過、0 失敗、0 跳過**。包含權限、學生資料投影與答案保密、單位評分、題庫核准／來源、重複題、選項答案分布、AI 結果保存、房間碰撞、配件、遊戲及新安全／並行測試。
- 全套 `scripts/check-*.mjs` **21 組通過**（launcher 另驗）：教師與學生導覽、RAG／組卷／換題、房間與家具／節慶、保存失敗重試、機台、換裝、作品審核、桌面／平板／手機尺寸。逐項結果見同目錄 `release-audit-evidence-2026-10-01.json`。
- 新 `check-release-csp.mjs` 使用正式 `dist-desktop` 和真實 HTTP／cookie，不只是 Vite 開發環境。Chrome 成功載入 3D 場景並保存房間。
- 新 `check-release-load.mjs`：100 位學生並行註冊、登入、交卷、保存房間與私人方案，300 次集中輪詢，30 局遊戲結算及重試。每個學生只能看到自己的學生／作答資料。
- 完整還原演練：SQLite 備份與 `server.key` 一起複製到另一個全新暫存目錄；比對完整工作區（班級、100 份作答、回饋、代幣、遊戲與收藏、房間及私人方案），核准題庫仍存在，假測試金鑰能解密呼叫模擬 AI，舊 session 無效且課堂預設關閉。
- 此次沒有使用真人 Gemini Key 進行教學品質抽驗；AI 測試使用可控制的回應。Firebase 雲端部署未作實際部署驗收。
- Mac／Windows 包已隨本修補重建；Mac Apple Silicon 另以新解壓的 GUI 實測通過。Intel Mac 只驗封裝／本機簽章，Windows 未在 Windows 真機執行。詳見證據檔，不能把重建當作真機通過。

### 本機負載如何解讀

測試在同一台 Mac、同一個 localhost 上執行，不經外網、不包含 100 台瀏覽器渲染，也不是 100 人實際教室的容量承諾。初次修正後量測：200 次學生存取 p95 約 579 ms、464 次狀態讀取 p95 約 84 ms；混合動作 p95 約 5.75 秒，最久約 14.66 秒，主要包含排隊的物理結算。完整重跑數值記錄於證據檔，以最終結果為準。

背景工作改善服務可回應性，但沒有消除慢電腦的結算排隊；必須以預期最低規格與外網完成 45–60 分鐘全課程測試，才能訂出支援人數與等待時間承諾。整份工作區目前仍是單一 JSON，歷史資料持續累積，亦需學期級資料量與長時間測試。

## 重現與交付

使用 Node 24 與鎖定的 pnpm 相依版本，在測試電腦執行：

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm build:desktop
pnpm build
node scripts/check-release-csp.mjs
node scripts/check-release-load.mjs
pnpm audit
```

其餘逐項瀏覽器腳本使用 Chrome，資料在暫存目錄或測試 localStorage；不要將測試資料目錄改指向正式課堂。安裝包驗證使用 `scripts/check-mac-package.py`，可重建後驗證 GUI 啟停、保留資料與解壓結構。

更新檔案不會替換正在執行的舊程序。由老師自行結束舊服務，再啟動新版並重新整理瀏覽器；保留原課堂資料及備份。此次 GitHub 發行維持 prerelease。

# v0.1.68 版面整理與角色編輯

## 頁面骨架
- 所有頁面依序為：標題（28px，與左側選單同名）→ 分頁 → 篩選列 → 內容；移除英文小標與標語式大標。
- 頂部「目前班級」固定顯示於所有教師頁，單行呈現，切換頁面時頂部不再位移。
- 新增 `src/layout.css`（載入於 style.css 之後）集中定義頁面骨架、按鈕層級與手機導覽。

## 視覺規則
- 字級統一為 12、14、16、18、20、24、28、32、40、48、56、64px（原 87 種數值）；最小 12px。
- ΔE < 3 的近似色合併（320 → 165 個色碼）；版面斷點收斂為 720px（手機）與 1024px（平板），另保留 380／480px 小螢幕微調。
- 停用中的主要按鈕改為虛線外框，避免看起來像可按的主要按鈕。

## 教師端
- 學習任務卡：草稿顯示「編輯題目」、已發布顯示「查看作答與批改」；交卷人數改為進度條；推理改編、複製與結束任務收進「更多」。
- 題庫與教材：改為清單，題目內容為主文字，年級／科目／單元為標籤；題數顯示於分頁（可用題目、待確認、已停用）；說明收合為「題庫怎麼運作？」。
- 批改與回饋：清單依任務分組；只看本班時不顯示班級欄。批改視窗改為近全螢幕的兩欄（學生作答／批改與回饋），可切換上一位、下一位，發布按鈕固定可見。
- 課堂獎勵：移除標語與重複的班級資訊區塊，今日發放數併入名冊標題。
- 新任務編輯：「出題目的」的長說明收合。

## 學生端
- 遊戲大廳、我的寶物房、班級作品展標題與選單同名；機台頁移除大標語，機台在第一個畫面出現。
- 寶物房工具分為「物品」（收藏與換裝、免費家具、節慶物件、角色徽章）與「房間」（空間佈置、調整物件）；未選取物件時提示「點選右側的收藏或家具開始佈置」。
- 代幣紀錄：學生檢視不再顯示只有自己名字的「學生」欄，標題下顯示目前代幣數。

## 手機
- 導覽改為底部分頁列。學生端 4 項；教師端顯示班級與上課、學習任務、批改與回饋、課堂獎勵，其餘在「更多」。
- 遊戲大廳改兩欄；寶物房與機台按鈕最小 44px。

## 角色素材編輯
- 角色卡新增「編輯」：帶入名稱、素材來源與圖片，表單標示「編輯角色」，可「保存修改」或「取消編輯」；不更換圖片則沿用原圖。
- 後端沿用既有 saveCharacter，帶入角色 id 即更新，識別碼不變，推理任務與徽章維持關聯。已發布推理任務保存發布時的角色名稱與圖片，草稿與之後發布的任務使用新版本。
- 未保存提醒只在內容與載入時不同才出現。

## 驗證
- Windows 測試環境：265／275 項自動測試通過；10 項未通過為備份、復原與外網通道的 Windows 環境測試，改版前即相同。
- `scripts/check-character-edit.mjs`：隔離資料驗證編輯後角色 id 與圖片不變、名稱與來源更新、取消編輯不保存、無頁面錯誤。
- 以測試班級擷取教師／學生各頁在 1440px 與 390px 的畫面比對改版前後。
- 伺服器端（desktop/、functions/）與資料格式未變更。實體 Mac、Safari 與行動裝置仍待驗收；本版為試用版。

# 快速出題與核准沿用（v0.1.39）

## 老師的操作

建立學習任務，填寫名稱、年級、科目及單元，預設選「快速組卷：已核准題庫（不使用 AI）」。可指定總題數，或填「選擇題8題，應用題2題」。選用的原題已核准且未修改時，直接預覽並發布，不必逐題勾選。

快速組卷以單元／標籤匹配，保留年級、科目、教材、學期與難度限制；不會自行放寬。它不解讀額外教材或排除條件：若輸入這類內容，會提示改用「AI 理解要求，僅使用已核准題」，不會悄悄忽略要求。後者需要老師已設定 Gemini 金鑰，最多使用意圖解析、候選相關性兩次請求，不生成新題。

題數不足時列出已找到題數及每種題型的缺額，保留原草稿。老師可明確選「使用這幾題」、調整要求，或切換「開發新題」。切換模式不會直接發送 AI 請求。

## 核准與發布

已核准題收合為預覽摘要，可展開修改。修改題目、答案、詳解或適用範圍，原核准不再適用；只確認變更題即可。新題確認後寫入題庫，供後續原題重用。已核准內容不顯示重複勾選框。伺服器仍驗證來源版本、停用狀態與內容，不只相信畫面的「已核准」文字。

## 測試與限制

168 項 Node 測試通過。新增測試涵蓋題型缺額、範圍隔離、忽略額外限制的防護、核准沿用、修改與停用阻擋、AI 模式不補新題，以及新題開發優先使用已核准題。

真實暫存 HTTP 教室與 Chrome 測試通過：沒有 API Key 組卷、明確採用較少題數、原題免勾選、修改後重新確認、保存重開沿用核准，以及手機寬度發布。沒有讀寫使用者正式教室資料。原有 RAG 新題開發、確認回存、修改失效及保存重開發布的瀏覽器回歸亦通過（AI 使用測試替身）。

這次降低出題端的重複工作，不將待審題自動改成已核准，也沒有宣稱所有年級全科已具備足量核准題庫。核准目前仍儲存在各老師的本機題庫；平台共用經審查題庫、參數化模板擴充、真實教學標準集與正式上市驗收仍需後續完成。現有數學驗算／單位檢查保留。

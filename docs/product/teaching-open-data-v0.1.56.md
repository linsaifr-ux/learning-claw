# v0.1.56 以教學需求為主的官方資料整合

本版修正 v0.1.55 將學校名錄讀表題直接放進所有科目出題畫面的問題。移除新建入口，保留舊任務、原始資料快照與驗證能力，不改寫教師已發布內容。

## 使用流程

教師填年級、科目、單元及題型要求。快速組卷只使用已核准題庫；AI 理解模式亦只使用已核准題。只有選擇「開發新題」時，題庫不足才可使用官方教學內容產生新題。未知教材版本或學期的官方來源不補入指定版本／學期任務。題目不足或檢查失敗保留原草稿，不自動換科目或替換為名錄讀表題。

官方來源新題需返回真實來源 ID 及逐字引用；程式核對引用存在於實際傳給模型的內容，再以另一次 AI 請求核對答案支持、範圍、題意唯一性與詳解。這是輔助檢查，不是獨立專家審定，也不是保證模型正確。教師確認後以官方來源紀錄存回已核准題庫，再次使用不需重複確認。

任務的教材搜尋沿用當次 AI 解析的概念；尚未解析時可用關鍵字或「AI 理解目標並找教材」。教材清單只支援推薦，不能作為題目答案依據。切換年級、科目或單元會清除舊附件，避免跨任務沿用不合適資源；搜尋中的過期回應會丟棄。

「重做選擇題錯題」明確標示為原題複習，沒有宣稱已生成新的補強題。回饋文字相同但教材更改時也能更新發布，不重複發放代幣。

## 實際資料

官方下載經 data.gov.tw API 取得資源網址，原始 SHA-256、下載位置與查核日期存入 teaching-sources.json。資料說明頁：

- https://data.gov.tw/dataset/41559：465筆，排除重複後440筆題目參考；保留原題及原答案，原資料未提供詳解與精確年級，不自動核准。
- https://data.gov.tw/dataset/41560：177筆，篩選國小／國中及允許的官方網址並去重後95筆教材連結；非全文、非題庫。連結可用性仍受原站影響，需教師預覽。
- https://data.gov.tw/dataset/8658：5,383筆物種文字知識；不等於5,383題。移除NULL、聯絡資訊與未使用欄位，保留形態、生態、分類、來源圖鑑等文字。未提供年級，不能直接宣布適合所有年級。
- https://data.gov.tw/dataset/174282：PDF已下載，版本為109年3月，含舊統計與圖表，本版不啟用其自動出題。
- https://data.gov.tw/dataset/6246：官方原始檔下載逾時，本版不假裝已匯入。
- 原愛學網清單繼續提供教材搜尋；學校名錄只用於選填班級背景。

這些來源的資料集授權標示為政府資料開放授權條款第1版。連結到外部作品不等於取得該作品全文的改作授權。本版不抓取影片、圖片或音訊。

## 維護與保存

- 新教學來源隨程式版本更新，將來源文字壓縮存入教師SQLite歷史快照，沿用既有完整資料庫備份；更新後仍能查看舊題引用來源。
- 「更新愛學網與名錄快照」只更新其標示的既有三份資料；不暗示已重新下載所有新教學內容。
- 可用 `python scripts/build-teaching-sources.py <官方下載目錄>` 重建；輸入為每個資料集的 `<ID>.json` 詮釋資料及 `<ID>.raw` 原始檔。輸出包含收錄／排除數量及原始雜湊。
- 學生端不取得來源題目答案、教師確認憑據、檢索需求或來源全文。官方教學來源查詢僅提供教師。

## 上市門檻與限制

本版不是全科題庫完成或全面上市認證。尚需三至九年級領域教師驗證適齡性、來源正確性、教材適切性與題意品質；以模型替身通過的整合測試不能當成真實Gemini品質評測。未處理的科目缺口仍須補充有權使用的題庫和教材。

氣象PDF與古蹟仍有上述缺口；外部教材連結需定期維護。Windows及Intel尚需真機測試；Mac仍為本機ad-hoc簽章而非Developer ID公證。Quick Tunnel維持既有方案與網址生命週期。正式教師資料庫未被本次測試操作，使用者自行重啟。

## 本版驗證紀錄

新增8項整合測試涵蓋原始資料分類、跨科與指定教材範圍、偽造引用／ID拒絕、獨立檢查失敗、首次確認與免API重用、歷史快照、學生答案保密及教材保存。完整回歸測試252項通過。

桌機與390px手機端到端測試已通過：不出現名錄讀表入口、官方來源新題、來源內容查看、確認、存草稿重開、發布、學生交卷、教材草稿及回饋、個別錯題複習與代幣。Gemini使用合成測試替身，未呼叫真實教師API；端到端結果不等於教學內容或模型品質評測。

三平台試用包均已同步v0.1.56後端、官方資料與前端；Mac Apple Silicon圖形啟動／停止、註冊、復原碼、加密備份匯出／預覽／還原、新密碼登入與正常結束測試通過。兩種Mac ZIP的權限、framework連結與本機簽章驗證通過；不等於Intel真機驗收或Apple公證。

# 新題、複習與錯題補強

桌面試用版 v0.1.43，Mac 與 Windows 共用。新任務預設「新題練習」。

## 教師流程
1. 選定班級，建立學習任務，填寫科目、單元及題型要求。
2. 選出題目的，再選原有的出題方式。新題練習可用不需 API Key 的快速組卷；複雜要求仍需 AI 理解。
3. 題庫不足時保留原稿，顯示缺額及排除的舊題數。可明確採用較少題數、允許複習舊題、調整範圍或開發新題。沒有暗中重複補滿。
4. 切換目的不更動已有題目，需按組卷才重新挑選。保存草稿會保留目的、舊題比例、錯題重做選擇、教材要求、方式及題數。
5. 已核准原題沿用核准；AI 新題及修改題仍需確認。發布時再次比對最新已發布內容，失敗保留編輯內容。

## 三種用途
- **新題練習**：排除本班、同科目全部已發布任務的相同與高度相似題目，跨單元名稱也會比對。草稿與目前任務本身不計入。
- **複習測驗**：允許舊題最多占 0／25／50／100%，優先選新題，並不保證精確比例。以實際發布題數計算，小數捨去；3 題的 25% 為 0 題，4 題的 25% 為 1 題。採用部分結果也遵守實際比例。同份試卷不允許重複同題。
- **錯題補強**：依本班同科目、同單元中有實際錯答的選擇題，由 AI 理解考點。預設使用新情境；需要重做錯題原題才勾選。沒有錯答證據會提示改用新題，不會推測開放題或未作答的錯誤。成語補強會限定可辨識的錯答成語，不套用一般練習的多成語比例。這是班級層級補強，並非個別學生推薦。

舊版本未記錄用途的草稿顯示為複習模式，請確認比例後發布。錯題補強自動切換至 AI 理解要求，避免不使用 AI 的快速組卷忽略考點。若已核准題庫不足，可明確改選「開發新題」。

## 邊界與驗證
比對會忽略題號、空白與一般標點，辨識選項重排；保留數值、小數與運算符號差異。長題幹採用文字片段相似度，不能保證辨識所有語意改寫。相同考點的新情境可出題，數值不同的計算練習也可使用。

RAG 可使用已出題的來源作為參考，但輸出仍需通過歷史檢查。傳給 AI 的歷史最多 150 題；伺服器最後核對完整歷史。重複或考點分布檢查失敗最多重試一次，可能增加一次 AI 請求；仍失敗就保留原稿。AI 自訂出題檢查失敗直接提示手動重試。新題仍需教師確認。

驗證採獨立暫存資料庫、模擬 Gemini 與真實本機 HTTP／Chrome。涵蓋班級隔離、草稿排除、偽造客戶端歷史、歷史題改選項、發布前歷史變動、部分組卷比例、RAG 重試、教師要求不下發學生、草稿設定恢復、手機操作與原有核准流程。不使用真實班級資料。這些檢查不代表全科語意品質或上市驗證已完整。

# 出題品質與上市驗收（v0.1.45）

## 本次修正與規則

以程式重排可安全移動的選項，而非只要求 AI 分散字母。整份新卷可移動的選擇題以隨機順序分配較均衡的答案位置；沒有鎖定題時，各字母題數相差不超過一題。局部換題計入保留題的答案分布，只調整新換入的位置，避免破壞老師已查看的內容。

正確選項文字不變，答案字母與明確的詳解引用一起更新。含「以上皆是」、相對位置、題幹／選項字母引用或無法確定的詳解字母時保留原序並提示。只有可確定的引用會改寫；不猜測化學符號、英文或複合選項的語意。已核准來源在發布時以可重現的排列轉換驗證等價，不能藉改詳解、答案或選項內容冒用核准。數學核對內容同步更新；新題仍待教師核准。

答案分布在教師編輯頁顯示，舊草稿可手動平衡。保存、重新開啟及發布不再次洗牌，已發布卷不可直接修改，學生看到與老師發布一致的版本。學生端作答前仍不取得答案、解析或核准憑證；繳交後依發布時答案評閱。

## 已有驗證證據

- 自動測試：1–20 題全 B，正確內容與分布、排列不修改原始物件、詳解引用、位置相依題保護、核准保留及偽造內容阻擋、數學驗算、重複選項。
- 真實本機服務配暫存資料庫：已核准題庫與模擬 AI 全 B 組卷、保存與發布、學生作答前答案保密、提交後正確判分。
- Chrome 桌面與手機寬度：分布顯示、手動平衡、免重複核准、草稿重開、發布後不變、重複題替換。
- 全站操作回歸：教師與學生導覽、手機溢位、未保存提醒、彈窗誤關、短螢幕、保存失敗重試與保存中停用。
- Mac 封裝另做乾淨解壓、簽章結構與暫存教室啟停驗證；不操作正式班級資料。

## 尚不能宣稱上市驗收完成

答案分布不是題意與答案正確的證明。尚須三至九年級各科人工標準集及實際教師試教，量測錯題率、範圍符合率、批改偏差與誤判，設定可接受門檻及回退方式。自動檢查仍不能驗證所有題意、圖片與語意等價。

Safari、iPad、Android、Windows 與 Intel Mac 真機、真實外網中斷及班級並發負載、長期資料還原、獨立安全檢查、帳號復原、正式簽署與公證亦尚未完整驗收。Chrome 手機寬度測試不能替代真機。完整門檻沿用 [上市前待驗證項目](release-readiness-2026-09-30.md)。此版本仍為試用版；不能用測試通過替代正式對外營運驗收。

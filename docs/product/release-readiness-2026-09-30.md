# v0.1.38 整合檢查與上市前待驗證項目

檢查日期：2026-09-30。結論：本版修正可重現的介面整合問題，適合繼續試用；尚不能視為已通過正式商用驗收。

## 本次修正

- 寶物房採同一工作區，娃娃、家具、節慶物件共用確認、保存、復原、複製及收回位置。無法使用的動作停用並保留位置。
- 預覽與操作列放在同一區域；工具清單獨立捲動。桌面、平板寬度、手機寬度及短視窗有對應配置。
- 保存後保留選取、工具區與捲動位置，不因關閉家具面板造成頁面跳動。
- 收藏位置及高度變動不重建 WebGL 畫布。其他必須重建場景的變更保留相機位置與目標。
- 保存失敗保留草稿，重試不重複加入家具；保存時禁止重複提交及修改。
- 房間、創作計畫及教師活動設定有未保存離頁提示；彈出表單輸入後關閉會提醒；登入處理中不能切換角色。
- 換裝只列擁有的配件，以實際模型縮圖呈現；明確區分已穿戴與被其他收藏使用。

## 正式對外營運前的驗收門檻

1. **跨裝置及可及性**：實測 Safari、iPad、Android、Windows、Intel Mac；包含觸控旋轉／擺放、軟鍵盤、瀏覽器縮放、鍵盤與螢幕閱讀器。確認操作列沒有遮擋，工具可完整操作。
2. **課堂負載與斷線**：以預期班級人數測試同時登入、作答、發幣、AI 批改與遊戲；記錄延遲、記憶體和低階裝置 FPS。實際外網中斷、重連、老師休眠與突然斷電尚需演練。
3. **教學內容品質**：以不同年級、科目及題型建立人工標準集，量測生成、單位判定、批改與學生回饋；不可把程式測試通過解讀成 AI 題意與評分永遠正確。保留教師確認。
4. **帳號與資料安全**：學生姓名＋生日登入辨識強度有限；正式大量使用前須完成威脅模型及獨立安全檢查，評估登入防猜、班級隔離、未成年資料告知、保存期限、刪除與帳號復原流程。
5. **安裝與更新**：Mac 目前為本機簽署、未公證，Windows 未正式簽署。需完成正式簽署／公證、乾淨機安裝、升級保留資料及失敗回退的實機驗證。
6. **備份與支援**：本次驗證可還原備份內的老師帳號；正式驗收還須用具代表性的班級、作答、收藏及加密金鑰進行完整災難復原，並明訂備份保存、客服及故障處理方式。

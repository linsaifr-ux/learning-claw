# 創作工作坊與班級作品展（v0.1.37）

## 已實作
- 學生寶物房：房間名稱、200字介紹、自由目標／靈感、自我標記完成、最多6款收藏願望，顯示已收藏及對應機台。創作計畫獨立保存，不扣代幣。
- 12款免費家具：三層展示架、階梯台、工作桌、小椅、櫃台、隔板、立燈、牆架、畫框、步道、植栽箱、展示牌。沿用三種配色及位置／角度／大小調整；可複製，家具與節慶物件合計32件、每款8件。
- 收藏可調高度以放上桌面／層架；這是手動高度調整，尚未實作家具表面自動吸附或碰撞。新增最近20步佈置復原，歷史只保留於本次編輯。
- 師生皆有「班級作品展」。學生自主投稿已保存的計畫與房間，不上传截圖。伺服器產生不可隨後續編輯變動的房間快照，使用相同3D引擎查看。
- 每學生最多一件投稿；待審／退回只對作者和老師可見。教師核准後僅本班可見，以創作者座號顯示，不提供生日、學習資料或其他同學的學生ID。自由文字仍需教師確認不含個資。
- 老師可退回修改／撤下展出；學生可撤回。重新投稿替換舊作品並重新審核，舊審核請求不能核准新版。

## 操作流程
1. 學生：我的寶物房 → 保存創作計畫 → 免費家具／收藏與換裝 → 保存佈置。
2. 學生：班級作品展 → 投稿已保存的房間。
3. 老師：班級作品展 → 選班級 → 查看作品 → 核准本班展出或給修改建議。
4. 同班學生：班級作品展 → 查看立體房間；可以轉動視角，不改動他人房間。

## 驗證與範圍
以隔離資料測試跨班隔離、權限、重複請求、重新投稿、撤回、保存及SQLite重啟還原。瀏覽器測試涵蓋計畫輪詢保留、願望、免費家具、配色、複製與復原、收藏高度、重新載入及手機作品預覽。
不宣稱已證明長期學習或留存效果；仍需實際班級跨週試行。尚未實作重複收藏兌換、教師指定收藏獎勵、多套房間存檔及自動對齊。

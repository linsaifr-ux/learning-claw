# v0.1.66 案件生成格式修正

使用者回報「成語大冒險2」編寫案件僅顯示操作無法完成。唯讀確認該任務有10題。未取得當次模型原始回應，因此無法判定當次是哪一欄不合格。

確定缺陷：parseDetective／cleanNarrative 的一般 Error 在 HTTP 邊界被遮蔽。改用安全 AIError，逐一檢查場景數、欄位型別與長度、結案選項及答案，錯誤僅包含固定欄名與數量，不回傳模型原文或憑證。

生成改用 responseJsonSchema，場景陣列精確等於題數、全部故事欄位必填並限定字數；指示精簡段落。只對案件提升輸出上限至16384 token、逾時至90秒。其他AI操作保留8192 token／45秒預設。不自動重試。不刪除、不覆寫既有草稿；只有完整通過檢查才回傳新案件。

回歸測試包含10題教師生成服務、精確schema、錯誤保留草稿、缺欄、超長內容、JSON圍欄及安全錯誤提示。未使用使用者API Key進行真實模型驗證。

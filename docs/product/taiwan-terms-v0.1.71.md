# v0.1.71 題目與推理劇情使用臺灣用語

## 做法
- `functions/taiwan-terms.mjs`：只自動替換在臺灣任何語境都錯的詞（視頻、軟件、打印、鼠標、屏幕、網絡、U盤、西紅柿、塑料、酸奶、初中、厘米、千克、千米、平方米、數字＋米、初一／二／三＋學年／生等）；菠蘿麵包、大年初一、玉米、橡皮擦／筋等保留。毫米是臺灣課綱用語，不換。
- 在臺灣也有正確用法的詞（質量、計算機、自行車、地鐵、智能、空調、數據、文件、程序、水平、土豆…）只在題目與案件編輯器顯示「用語提醒」，由老師判斷。
- AI：系統指示加入臺灣用語要求與對照；服務層包住所有 AI 回覆，換用語並轉換零星簡體字（超過 3 個簡體字視為失敗、請老師重試，避免繁簡混雜）。
- 題庫：存入、匯入時換題目、選項、答案、詳解的用語（不轉簡體，原始來源保留）；啟動時把舊題目就地修正、不改版號，已出題任務的來源連結不受影響。實測內附補充題庫約 590 處、CMATH 來源約 760 處會被修正。

## 驗證
- `tests/taiwan-terms.test.mjs`：替換與保留清單（菠蘿麵包、大年初一、詩云、玉米、自行車道、智能障礙、東京地鐵、質量守恆、計算機不改）、AI 回覆經服務層後已換用語、系統指示含臺灣用語要求、題庫存入與啟動修正（版號不變）。
- 編輯器「用語提醒」以瀏覽器確認顯示。
- 打包版 Windows 實測：AI 回覆與題庫存入都換成臺灣用語。
- 真實 Gemini 的整體用語品質未用教師金鑰大量測試；替換表只涵蓋常見詞，仍建議老師發布前閱讀。

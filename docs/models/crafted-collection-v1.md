# 原創收藏模型精製第一批

版本：v0.1.32；日期：2026-09-27。

本批為可運行的第一版美術升級，使用原創程式幾何和程序材質，未使用Blender雕刻、AI生成圖片或第三方模型。不是照片級布偶、軟體變形或學生偏好驗證結果。研究中的Blender雕刻、高低模烘焙與完整LOD仍屬後續製作工作。

| ID（不變更） | 外觀變化 | 三角形／網格 |
|---|---|---|
| polar | 共用白熊GLB上增加獨立織紋材質、雪花刺繡、腳掌與背部縫線；原小熊材質不變 | 31,960／57 |
| robot | 烤漆與金屬材質、玻璃面板、螺絲、關節、鞋底、胸部儀表與背部散熱孔 | 9,280／7 |

計數為獨立收藏本體，不含膠囊、配件、陰影重繪及場景；網格數不等於整個畫面的總draw call。白熊沿用原模型，尚未達研究提出的20k三角形起始預算，需在後續LOD製作處理。手機尺寸Chrome已檢查呈現，未量測手機真機30fps，不能宣稱已通過真機效能驗收。

## 重用與相容

- `src/model-craft.mjs`：確定性128×128程序表面材質、按材質合併靜態幾何。供下批資產重用，不需API或額外下載。
- `src/crafted-collectibles.mjs`：機器人及鯨魚唯一幾何來源；圖卡配色與特徵同步。
- `src/polar-craft.mjs`：在白熊複本上製作，保留部位名稱與配件接點。
- `World.toy()`是機台、獲獎展示和寶物房共同入口。機器人與鯨魚仍使用原膠囊碰撞，白熊仍使用原熊碰撞外形。
- 不改收藏ID、稀有度、取得率、代幣價格或庫存資料；既有學生收藏會顯示新外觀。
- 本批材質／幾何為本專案程式原創，套件依各自LICENSE；不新增角色IP或外部美術授權。

## 驗證

8項相關測試：模型幾何預算、有限法線與UV、鯨魚外向法線、白熊材質隔離及外形邊界、原GLB兩側配色、機台權限與各新膠囊獎池實際落獎。

瀏覽器：三款獲獎展示、390px手機尺寸、膠囊引用相同美術版本、原熊材質未被污染；另檢查既有房間與配件流程。三款實際展示圖由`tests/browser/crafted-gallery.html`產生，沒有以概念圖替代模型截圖。

## 下一批開工門檻

先用這三款實際模型收集三／四、五／六、七至九年級學生回饋。記錄偏好理由與操作問題，避免直接把此批製作成果當作市場驗證。再決定擴大模型、細節改版或房間組合套件。維持既有收藏相容，按小批內容維護。

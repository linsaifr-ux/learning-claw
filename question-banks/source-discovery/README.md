- `cmath/cmath_dev.jsonl`：上游原檔，未改寫。

## 如何接成可靠的 RAG 題庫

1. 優先使用臺灣公開原卷建立題目／答案／圖片對應；先確認可採用的使用範圍，再決定是否可隨軟體散布。
2. 按108課綱通用單元建立年級、學習目標、題型及難度；保留原版本、學期與出處供追溯，不把不同版本同名單元直接視為等價。
3. 附答案者保留來源答案。沒有答案的試卷，任何AI補答均標成新草稿；公式、數值、單位和題意另驗證，不能當官方答案。
4. 教師審核後才進正式檢索；AI根據來源延伸出的新題另外標示、另行審核。
5. 以「年級 × 科目 × 單元 × 題型」可用量查缺，而不是用下載檔案總數宣布全科完成。

目前仍欠九年級逐科盤點、國小非主科、本土語文、實作與口語評量，以及所有來源的逐單元覆蓋驗證。**尚未達到三至九年級全科日常教學完整覆蓋。**

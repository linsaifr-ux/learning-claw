# 網路題庫資料庫：收集紀錄與使用方式

更新：2026-09-26。目標為國小三年級至國中三年級全科；**目前完成首批來源整理，未完成全科覆蓋，沒有自動審核題目**。

## 已建立

- **810 題國中來源文字選擇題，全部完成一次 AI 整理**：452 題補上建議年級、單元與詳解，358 題需核對（超出國中、缺少資料、答案不符、格式或詳解有疑義）。
- **452 題整理草稿**：國文104、數學56、自然190、社會102；全部尚未經教師審核。整理時未提供来源答案給 Gemini，獨立解答後比對，仍非正確率保證。
- **20 題國小三年級國語原卷拆題**：來源「三下國語期末考試題」，作者張滄敏（新北市立海山國小），原站標示公共領域。9題選擇、5題修辭、3題造句、3題感官摹寫。原卷未附答案，參考答案及詳解由專案整理，非官方答案。
- 合計 **472 題可加入待審核題庫的草稿**，不含358題疑義項目。
- **246 筆官方試卷來源**：索引教育大市集三至九年級的 55 個分類，逐筆讀取授權標示與下載資訊。
- **148 題隔離紀錄**：可能依賴圖片／表格／底線、疑似遺失次方格式、第三方閱讀素材待核或欄位不完整等。未打包隔離題目的正文。
- 題目來自 iKala TMMLU+ 的五個 junior 子集，已收集 dev/train/val/test 四種分割並去重；原題與來源答案保留；Gemini 3.5 Flash Lite 產生的建議年級、單元與詳解另存為 AI 整理草稿，未改寫原始資料。

## 在系統使用

教師題庫 → 網路題庫資料庫 → 瀏覽已收集的網路題庫。

1. 預設顯示「已整理（待教師審核）」，可搜尋科目與關鍵字，查看來源與詳解草稿。
2. 按「將全部已整理題目加入待審核題庫」，一次加入472題，已存在的題目會略過。此操作不代表審核通過。
3. 逐題核對年級、單元、答案、詳解與使用權利，確認後才會進入 RAG 檢索。可先搜尋「迫不及待」或「流連忘返」處理三年級成語來源。
4. 「AI 與來源答案或資料有疑義」列出358題，提供疑義原因，不能以批次按鈕直接加入。若人工修正完成可另存並審核。
5. 「原始國中文字題」保留810題來源文字；「外部試卷來源」保留246筆原站資訊，這些連結不是已拆題的資料。

## 範圍缺口

- AI 建議年級與單元不等於官方課綱對應；810 題不能宣稱為已驗證正確的題庫。
- 國小其他年級與科目、國中英語、本土語文、藝術、健康與體育、綜合活動、資訊科技、生活科技及校本課程，目前未建立完整逐題正文。國小只收錄上述單份三年級國語原卷的20題，無法代表整學年內容。部分有官方試卷連結，但不等於涵蓋所有課綱。
- 教育大市集目錄偶有分類不吻合，採原站標籤記錄，使用前須核對實際卷面及年級。
- 找到的「三年級成語測驗題目」標示著作權所有且需要登入，未下載、未仿造原題，也未用 AI 新編題冒充該來源。
- RAG 檢索仍只使用教師已審核的本機題庫，不會直接引用這批未完成整理的文字題。

- [學習扶助教材](https://exam.tcte.edu.tw/tbt_html/index.php?mod=EbookNoSignIn/ebooklist_public)：版權標示國教署所有，收錄入口，未視為自由改作或 AI 再利用授權。
- [國中教育會考](https://cap.rcpet.edu.tw/examination.html)：收錄官方入口；圖片、聽力、題組及答案需要另外配對，未直接轉為文字題。

## 檔案與重建

- `prepared-questions.json`：810題整理結果與疑義原因；452題可加入待審核題庫。
- `elementary-questions.json`：20題國小拆題、作者、原站授權、下載檔案SHA-256與答案草稿標示。
- `sources.json`：55 個分類、246 筆試卷來源及主要入口。
- `staging-questions.json`：810 題待整理資料，使用 `learning-claw-staging-v1`，**不是一般題庫 JSON 匯入格式**，須透過新介面指定範圍。
- `quarantine-index.json`：148 筆隔離理由，不含題目正文。
- `coverage.json`：各年級的原站分類計數（不是逐題數）。
- `summary.json`、`download-manifest.json`：數量、下載版本與完整性資訊。
- 重建：`python3 scripts/collect-web-question-bank.py`。僅讀公開網址，最多三個並行請求，保留本機快取；失敗會記錄，不越過登入或付費限制。題庫快照同步到 `desktop/library`，隨教師程式打包。

AI 整理結果匯出：`node scripts/export-prepared-library.mjs work/library-preparation-progress.json`，會檢查原題、選項、來源答案、ID與狀態。進度與金鑰不隨程式打包。`scripts/build-elementary-library.py` 從已下載的指定原卷建立國小資料，未依賴登入Cookie或自動提取帳密。

- 第四學習階段代碼對應國中7–9年級範圍，不假裝已分到某一學期。國中目前沒有收錄社群通用主題，本土語文各語種課綱與語料也仍有缺口。

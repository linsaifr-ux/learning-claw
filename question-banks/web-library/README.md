# 學習有爪題庫快照 v0.1.53

此資料夾是來源與候選題的可追溯快照，沒有教師帳號、學生資料或已核准的教師題目。不是可直接認定全科完成的正式題庫。

候選共 3,167 筆：欄位齊備 1,553、待補資料／活動草稿 1,253、疑義 361。原始來源文字另存，不可與整理結果重複加總。`summary.json` 的 810 題統計專指原始國中來源批次；全體盤點以 `curriculum-bank-audit.json` 與應用程式顯示為準。

本次新增 1,688 筆，包含 756 筆數學數值變式、80 筆成語、99 筆英語、21 筆國中跨科任務、33 筆臺灣台語以及 699 筆教師帶領活動。換數字與跨年級共用題不等於不同考點。台語僅文字詞義與語境，未包含完整腔調／聽說教材。

## 使用

最新版桌面程式已內附這些資料。教師題庫 → 開啟課綱與資源中心 → 選年級、科目、單元 → 加入本單元候選題。或於「瀏覽已收集的網路題庫」依年級與科目查看。候選須匯入本機後才能供 RAG 選題；可於出題時只核准當次選用題目，核准結果保留供下次選用。

本資料夾 JSON 包含來源索引與額外中繼資料，不能全部直接丟入一般題目 JSON 匯入欄位。請使用內建資料庫介面。疑義題須先修正；活動草稿須補教材及確認規準。

教師電腦版啟用教學

老師啟動電腦程式，學生使用網頁。學生只在老師開課期間連線；關機、休眠或斷網會中斷課堂。

1. 啟動與建立老師帳號

解壓縮對應電腦的完整下載包，開啟「學習有爪.app」或「學習有爪.exe」。依啟動畫面開啟教師網站，使用 Email 與至少 8 字元密碼建立帳號；首次設定依畫面填入設定碼。老師不使用 Google 登入。

請妥善保管密碼。請先停止教室服務，在桌面啟動中心「帳號與備份」建立復原碼並另行保管。忘記密碼時可用復原碼重設；若兩者皆遺失，沒有通用密碼可繞過登入。

2. 建班級與開課

進入「班級與連線」建立班級並開放學生註冊，再啟動外網連線與課堂。把該班級的學生入口連結傳給學生；不要分享教師本機的 127.0.0.1 網址。重新開啟通道後請複製最新的學生入口。

3. 學生登入

學生開啟老師提供的班級連結，使用姓名、生日月日註冊／登入。同名學生請由老師安排不同辨識名稱。老師可在註冊完成後關閉註冊；結束課堂會中止學生連線。

4. 教師 AI 金鑰

  1. 前往 Google AI Studio 建立專用 API Key；免費額度與可用模型依 Google 帳戶及政策而定。
  2. 在「AI 與設定」貼上金鑰並儲存，再測試連線。不要貼在聊天、公開程式碼或學生頁面。
  3. 學生不直接操作 AI。老師使用 AI 理解出題要求、延伸題目、批改與分析；AI 新題仍需確認，不能把 AI 判斷視為一定正確。

請閱讀 Gemini API 使用條款。啟用前確認機構的資料處理要求；不要在題目與學生自由文字中傳送敏感資料。

5. 題庫與發布

到「教師題庫」匯入可使用的來源。已核准題目可直接組卷；待審及新 AI 題需教師確認後再發布。支援某科目的介面不代表該年級、單元已有足量題目，請先確認本課的題庫覆蓋。

6. 保存與備份

教師電腦保存班級、作答、收藏與金鑰資料。啟動時系統會備份資料庫及加密用的 server.key；兩者必須一起保管。完整退出程式後，再由管理者複製資料目錄到安全位置。只備份安裝包並不等於備份課堂資料。

備份含學生資料與解密所需檔案，不可公開分享。請停止教室服務，於「帳號與備份」使用至少 8 字元備份專用密碼加密匯出。還原前會顯示備份範圍並要求確認取代；還原後產生新復原碼。全新電腦應使用最新備份，刪除前的舊外部副本不會自動知道後來的刪除。

學生資料管理

教師網頁「班級與連線」可預覽學生／班級範圍並匯出教學資料；刪除需先下課、重驗老師密碼與勾選確認。刪除包含相關學習、收藏與展示資料，並清除程式管理中的舊備份。自行匯出的副本及已傳送第三方的內容需另行處理。

7. 上課前驗收

請用獨立學生帳號與外部網路測試：入口登入 → 收到任務 → 作答與逐題回饋 → 收到代幣 → 夾取入庫 → 房間保存重新開啟。另確認重新開課後連結可用。

目前為試行版，每位老師最多 100 位學生。臨時外網通道不保證可用率；正式營運仍需穩定連線、真機與負載驗收、資料治理及安全檢查。雲端 Firebase 部署是另一套管理者流程，請依專案 README 設定 Email 登入與後端，不能只上傳網頁就啟用。

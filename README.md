# 學習有爪 · Learning Claw

## 主題機台、娃娃換裝與寶物房（v0.1.26）
新增森林郵局、星際採集站、奶油點心屋三款主題機台；目前共用既有三爪物理與三款娃娃獎品，差異為機台外觀。入場記錄所選機台，完成當局才能切換，不改變代幣費用或獲獎機率。

寶物房新增木作收藏室、星光觀測室與花園玻璃屋，搭配三款地板、圓形／雲朵／無地毯，以及窗框、植物、展示櫃門、燈具、書本與吊飾等3D細節。節慶主題仍由老師開放。選收藏中的娃娃可進入換裝鏡，搭配皇冠、貝雷帽、星星髮飾、圍巾與領結；配件免費、展示使用，不影響夾取碰撞。按「保存佈置」保存每隻娃娃穿搭，收回收藏庫後仍保留。

139項自動測試通過；Chrome驗證換裝、保存重開、收回保留穿搭、390px手機畫面及機台鎖定。手機視角會調整以容納整個寶物房。

## AI 出題格式診斷（v0.1.25）
AI 自訂出題與 RAG 延伸共用逐題格式檢查。錯誤會指出題號、缺少欄位、題數或題型配額差異，不再統一顯示格式不完整。相容完整 JSON 程式碼外框、全形／小寫選項字母、非選擇題的數字答案及明確標示為 application 的題型。缺答案、缺詳解、無效來源及不符配額仍拒絕；不猜補內容，不自動增加 AI 重試呼叫。保留算式驗證與教師核准要求。這是格式處理修正，不代表語意正確率保證。

## 出題時確認並同步題庫（v0.1.24）
老師無須先審完整個題庫。出題從符合範圍的待審核與已核准題目挑選，只需確認本次使用的題目；勾選後同步記錄為已核准題庫，未選題維持原狀。AI 延伸題確認後另存為已核准新題，不會連帶核准參考原題。缺詳解須先補齊，修改後須重新確認，未完成確認不可發布。

已核准且未變更的原題可再次使用。重複確認不會新增重複題，來源版本變更或停用會阻擋發布。保存重開草稿保留有效確認紀錄。詳見 [目前操作流程](RAG-QUESTION-BANK.md)；下方舊版本紀錄中的預先審核限制已由本版調整。

## 授權題庫拆題與續作（v0.1.23）
新增649題來源候選，含400題CMATH數學及249題學校文字題；92題資料已補齊、554題待補詳解或範圍、3題有疑義，皆需教師審核。新介面可查看51份原卷的處理進度；缺圖、公式版面與題組保留原卷，不當作完整題目匯入。

AI可接續補充下一批來源題，隱藏來源答案後獨立解題，比對不一致時保留疑義。原始答案不被AI覆寫；重新匯入只更新未經老師修改的來源草稿。授權依使用者確認記錄，保留出處及各來源權利聲明；仍未完成三至九年級全科日常教學覆蓋。詳見[題庫整理說明](question-banks/web-library/README.md)。

## 108課綱與官方資源搜尋（v0.1.22）
教師題庫新增「108 課綱與教學資源」：依年級盤點各科已審核與待審核題數，分開顯示417個國小社群規劃主題及官方文件代碼索引。這些是規劃資料，不是新增的已審核題目；國中通用單元與逐題對應仍待完成，不能宣稱已支援三至九年級全科日常教學。

可儲存獨立的教育大市集API金鑰，使用官方全文檢索取得來源、年級、領域、授權及附件連結。金鑰以AES-GCM加密存於老師電腦；學生無存取權，API錯誤不回傳原始網址或金鑰。搜尋結果不會自動匯入題庫，仍需確認授權、附件內容與答案。申請送出不等於核准，需取得金鑰後才能測試。

## 題庫整理與 AI 理解出題（v0.1.21）
出題流程改為 AI 解析教師的口語要求與題型配額，再限定年級、科目、版本、學期及難度檢索已審核題庫，核對候選題相關性後組卷；不足時產生有來源的延伸草稿。需要 2–3 次 Gemini 請求，沒有已審核來源時不呼叫模型。詳見 [RAG 操作說明](RAG-QUESTION-BANK.md)。

已下載 810 題國中來源文字題，AI 建議分類、獨立解答與詳解，疑義題另外列出；另由標示公共領域的國小三年級國語原卷拆出 20 題。原卷未附答案，新增參考答案均標示為整理草稿。教師可一鍵加入待審核題庫，確認後才進入 RAG。**仍未完成全科覆蓋，AI 整理不等於教師審核或正確率保證。** [題庫數量、來源與缺口](question-banks/web-library/README.md)。

## 圖形教師啟動中心（v0.1.16）
下載並完整解壓縮後，Mac 開啟「學習有爪.app」，Windows 開啟「學習有爪.exe」。不需操作終端機；Windows 請保留整個解壓縮資料夾，不能只搬移 exe。Mac app 可獨立搬移。
選「線上教室」並勾選通道使用同意後按啟動，或選「本機備課」。服務就緒後按「開啟教師網頁」，到「班級與連線」開始上課並分享學生入口。首次教師設定碼直接顯示在啟動中心。關閉時會詢問是否停止服務；也可隨時按停止，資料持續保存在原本位置。
更新前請自行停止舊版服務。若連接埠或資料已被另一版使用，啟動中心會提示，不會強制關閉其他程式。Mac 仍未經 Apple 公證，Windows 尚未提供發行者簽章；這是可攜執行程式，不是安裝精靈。外網仍採測試用 Quick Tunnel。

封裝開發流程：先建置 `dist-desktop`，以 `scripts/fetch-electron.py` 下載校驗 Electron 執行環境，再執行 `scripts/package-mac.py`、`scripts/package-windows.py`；兩者會自動呼叫 `scripts/package-launcher.py`。封裝流程驗證官方 Electron SHA-256，產生 Mac app（保留 framework 符號連結）與 Windows GUI exe。Node 仍使用獨立執行環境以保持 SQLite 相容性。Electron 下載快取不提交 Git。

# 寶物教室 · Treasure Classroom

> **最新方向：Windows 老師電腦伺服器。** 學生只在上課時連線，帳號、資料與 AI 金鑰改存老師電腦。請讀 [Windows 使用說明](desktop/WINDOWS-GUIDE.md)。Firebase／Render 是保留的舊架構，不是 Windows 版必要服務。

> **目前部署方向已改為免費方案**：Firebase Spark + 可搬移的 Node.js 後端。老師 Email／密碼登入、學生姓名＋生日月日登入。請以 [免費部署手冊](FREE-DEPLOYMENT.md) 為準；不要沿用 Cloud Functions／Blaze／Google 登入部署方式。

供國小三年級至國中三年級使用的課堂獎勵與學習平台原型。React + Three.js + Rapier + Firebase。

## 現在可以體驗

- 老師建立班級／學生，個別、小組、全班發代幣，調整餘額，撤銷整批誤發並保留紀錄。
- 全科目與自訂科目，七個年級。建立選擇、簡答、作品／實作說明題；保存草稿、發布、學生作答、老師批閱回饋與任務獎勵。
- 實際 3D 機台、三指馬達關節、模型凸包碰撞、240 Hz 物理步進、真實開洞與取物槽；寶物通過出獎通道才獲獎。原創小熊、小兔、小貓 GLB 模型。
- 觸控／滑鼠搖桿與鍵盤控制，六種視角及自由旋轉。俯視模式隱藏頂蓋供瞄準。
- 每位學生獨立收藏房：選取、定位、旋轉、收回收藏、改變牆色、保存佈置。
- 老師控制中秋、萬聖、聖誕、新春活動。結束活動仍保留已完成佈置。
- 教師 Gemini 金鑰欄位、建立金鑰教學、正式版安全儲存／刪除／測試 API；出題與分析的後端程式已備妥。
- 電腦、平板、手機響應式介面與螢幕方向鍵。

## 目前狀態，請先讀

**尚未接上 Firebase 專案，故目前運作於本機示範模式。** 資料保存在此瀏覽器的 localStorage；不會跨裝置同步，也不是正式登入權限。示範切換老師／學生只是試用介面。請勿在示範模式輸入真實學生資料。AI 示範模板明確標記，沒有真的呼叫 AI，也不會儲存輸入的金鑰。

Firebase 雲端程式、權限規則及部署設定已提供，但尚未以你的雲端專案部署或做真實帳戶端到端測試。AI_ENABLED 預設 false；在成人教師工具的服務適用性與資料處理條件確認後，再由管理者啟用。

夾娃娃目前是**可玩的剛體物理原型**，不是商用等級的布偶軟體模擬。模型有原創實體五官、蝴蝶結與縫線，尚未完成高解析布料貼圖、毛絨、受壓變形與細緻聲音。收藏圖鑑使用原創向量插圖，3D 場景使用真正 GLB 模型。iPad／iPhone／Android 真機的效能仍需實測。

## 在自己的電腦啟動

安裝 Node.js 22 LTS 與 pnpm 11。於本資料夾執行：

```sh
pnpm install
pnpm dev
```

打開終端顯示的網址（預設 http://127.0.0.1:5173）。同一台電腦可用 `pnpm build` 和 `pnpm preview` 體驗正式建置。

```sh
pnpm test
pnpm build
```

## 快速體驗順序

1. 老師端點選小宇，按「＋3」與「發放代幣」。
2. 點「體驗學生端」，投入 3 枚代幣，使用方向鍵／螢幕方向鈕瞄準，再下爪。
3. 進入「我的寶物房」，點選收藏後點房間地板擺放。可旋轉、收回、改牆色，最後保存。
4. 老師端的「節慶活動」切换主題並開放，學生即可換上佈置。
5. 老師建立學習任務並發布 → 學生作答 → 老師「學習觀察」批閱，代幣只發放一次。
6. 「AI 與設定」提供教學與 Firebase 設定入口。示範模式不呼叫真實 AI。

## 免費部署與登入

請依 [免費部署手冊](FREE-DEPLOYMENT.md) 設定 Firebase Spark + Node.js 免費主機；網站內的 `/free-setup.html` 也提供說明。只部署 Hosting 和 Firestore 規則，不使用 Cloud Functions、不升級 Blaze。Render 免費主機不加入付款方式；達用量上限可能暫停，不能保證永久免費或全天不中斷。

老師以 Email／密碼註冊、驗證信箱，經管理者授權後使用老師端。老師建立班級後可開放／關閉新生註冊，分享班級連結；學生以姓名和生日月日註冊及登入，不需要 Email。生日只保留有伺服器秘密保護的雜湊，不保存明文或出生年份。

## 教師 Gemini 使用方式

在「AI 與設定」依步驟前往 https://aistudio.google.com/apikey 建立專用金鑰，檢查專案層級與模型額度，安全儲存後測試連線。免費额度不是每支 Key 各自一份，而是依 Google 專案。教師後端限制每 10 秒一次、每天 50 次（測試連線也計入）。配額錯誤不會偷偷改用其他模型。

教師工具不由學生作答直接觸發。AI 草稿必須老師審閱後發布；分析只传題目、作答與學習目標。自動移除名單中的姓名、常見電子郵件與手機號碼不能取代人工檢查，自由文字仍需教師先檢查。

## 架構與可用範圍

- `src/App.jsx`：老師／學生工作流程。
- `src/World.jsx`：3D 夾娃娃機與收藏房。
- `functions/domain.mjs`：共用資料規則與不可重複結算的操作。
- `functions/physics.mjs`：瀏覽器與後端共用固定步長模擬。正式版遊戲種子由伺服器產生，目標鎖定後伺服器重播，忽略客戶端獎品宣稱。
- `functions/index.mjs`：Firebase callable functions、教師權限、交易、安全金鑰與 Gemini 呼叫。
- `firestore.rules`：客戶端唯讀自己獲授權的視圖；所有寫入經後端驗證。
- `scripts/build-models.mjs`：重新產生原創 GLB 模型。

本版以每位老師的工作區文件作為交易單位，設有最多 100 位學生與約 700 KB 狀態上限，適合小規模試行，**尚非長期全校正式架構**。長期上線前應把課程、作答、帳本分拆為可分頁的子集合、加入歸檔、轉班／升級流程、帳號停用及匯出管理。既有資料達上限時會拒絕操作，避免靜默遺失紀錄。

作品／實作題目前接受文字描述與教師評分，尚未提供照片、音訊或影片上傳。此版本提供全科目框架，不內建已校對的七個年級全科教材庫，也不宣稱各科 AI 評量效度已驗證。

## 驗證

- 領域測試：批次原子操作、重複請求、撤銷、餘額、角色限制、收藏所有權、重複批閱／獎勵。
- 物理測試：固定種子與操作結果可重播，超範圍輸入拒絕。
- 瀏覽器人工測試：發幣→扣幣→夾取→收藏，任務發布→作答→批閱，以及行動版排版。
- Firebase 真實部署、App Check、Gemini 真實連線與跨裝置帳號流程須在建立專案後驗證。
